01 / INTRODUCTION

Security, built
from logic.

A password check is simple in concept. This project makes the journey visible: parallel inputs become serial data, the received bits are compared, and a status response travels back to the master.

A / THE PROBLEM
≋

Too many wires.
Too little feedback.

Parallel data can require a separate wire for each bit. Our design demonstrates how shift registers move data over a shared clocked serial link and return a comparison result.

PROBLEM STATEMENT↗
B / THE METHOD
⌁

Shift. Compare.
Respond.

A 74HC165 serializes the entered value. A 74HC595 reconstructs it for comparison. The result is encoded and shifted back.

SYSTEM METHOD↗
C / THE OUTCOME
◉

One result.
Two clear states.

Matching values produce an access-approved state; a mismatch produces a denied state, shown by the status indicators.

EXPECTED BEHAVIOUR↗
✳

Design principle — use a shared clock for coordinated shifting, then update the parallel outputs only when the received bits are ready.

STATUS FEEDBACK
U1 / U6

74HC165

Parallel-In, Serial-Out shift register. Captures parallel status/password bits and shifts them out serially.

PISO
U2 / U7

74HC595

Serial-In, Parallel-Out shift register with a separate output latch for stable displayed outputs.

SIPO
U4

74HC85

4-bit magnitude comparator. The design uses two bits; unused higher-order inputs are tied to defined logic levels.

COMPARATOR
U5

74HC32

OR gate combines A<B and A>B to generate a mismatch signal.
